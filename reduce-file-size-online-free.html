How to Reduce File Size: By File Type

Images (JPG, PNG, WebP)

Use the Image Optimizer. Set quality to 80% for web use, 60% for email, 50% for small targets like 100KB or 200KB. JPG images are re-encoded with intelligent quantization; PNG files convert to WebP for maximum reduction.

PDF Documents

Use the PDF Optimizer. The tool parses your PDF structure using pdf-lib, re-encodes embedded images, and strips invisible metadata. A 20MB scanned PDF typically compresses to under 2MB with text remaining sharp.

Videos (MP4, WebM, MOV)

Use the Video Reducer. Powered by FFmpeg compiled to WebAssembly, it re-encodes in H.264 at configurable CRF values. A 500MB 4K video reduces to under 100MB at 75% quality with no visible difference at 1080p.
